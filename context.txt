────────────────────────────────────────────────────────────────────────────────
  PROJECT OVERVIEW
────────────────────────────────────────────────────────────────────────────────

A mobile-first, single-page giveaway landing page for a collaboration between
Khayfer Liquidation and PoncakeA&A. Users scan a QR code on a purchased pastry
container, land on this page, and enter the giveaway via an embedded Gleam.io
widget. The page is fully bilingual (English / Spanish), toggled in-page with
no page reload. It is a static HTML file with no build tools, no frameworks,
and no backend — deployed via GitHub Pages.

Giveaway details:
  - Prize: Summer Gift Basket (~$50 retail value)
  - Entry period: May 19–23, 2025
  - Winner announced: May 24, 2025
  - Sponsor: Khayfer Liquidation, Russellville, AR
  - Entry method: Gleam.io widget (https://gleam.io/TJ05k/poncakeaa-khayfer-summer-giveaway)

Partners:
  - PoncakeA&A          — pastry maker, giveaway co-host
  - Dreami Tea          — in-person pickup location (Russellville, AR)
  - Khayfer Liquidation — giveaway host and prize sponsor

────────────────────────────────────────────────────────────────────────────────
  HTML SECTIONS — DETAILED DESCRIPTIONS
────────────────────────────────────────────────────────────────────────────────

  div.lang-bar
    Purpose: Sticky bar at the very top. Contains one button (#lang-toggle)
             that toggles between EN and ES with onclick="toggleLanguage()".
    Behavior: Stays fixed at top: 0; z-index: 100.
    Key attribute: aria-label on the button updates dynamically per language.

  header.site-header
    Purpose: Main hero header with coral-to-peach gradient background.
    Contains: Collab badge (data-key="headerTagline"), emoji, h1 (data-key="headerTitle").
    Decorative: ::before (☀️ emoji, opacity 0.2) and ::after (🌊 emoji) via CSS.

  section.hero
    Purpose: Giveaway dates band.
    Contains: .dates-badge with .dates-main (data-key="heroDates") and
              .dates-announce (data-key="heroAnnounce"), plus .hero-tagline
              (data-key="heroTagline").

  section.steps-section  [id="how-to-enter"]
    Purpose: "How to Enter" — 3 numbered step cards.
    Structure: .steps-list > .step-card (×3)
               Each .step-card has .step-number (1/2/3) and .step-content (h3 + p).
    Current steps:
      1. Buy a Pastry          (data-key: step1Title / step1Desc)
      2. Scan the QR Code      (data-key: step2Title / step2Desc)
      3. Enter via Gleam Widget (data-key: step3Title / step3Desc)
    NOTE: Was 4 steps historically. Step 4 ("Bonus Entries") was removed.

  section.prize-section
    Purpose: Prize display — Summer Gift Basket.
    Structure: .prize-basket > .prize-header (gradient, emoji, h3, value badge)
               + #prize-list (ul, rendered by JS renderPrizeItems())
    NOTE: The prize items list is populated by JavaScript on load and on each
          language toggle. Do NOT add <li> items directly to #prize-list in HTML.
          Edit the prizeItems array in the translations object instead.

  section.partners-section
    Purpose: Three partner business cards.
    Structure: .partner-cards > .partner-card (×3)
               Each has: .partner-card-header (.partner-icon + h3), <p>, .partner-links
    Partners and their social links:
      PoncakeA&A:
        - FB: https://www.facebook.com/PoncakeAA/    (.social-btn.facebook)
      Dreami Tea:
        - FB: https://www.facebook.com/dreamitea/    (.social-btn.facebook)
      Khayfer Liquidation:
        - FB: https://www.facebook.com/khayfer       (.social-btn.facebook)
        - IG: https://www.instagram.com/khayferliquidation/  (.social-btn.instagram)
    Partner icon colors:
      .partner-icon.poncake  — yellow-to-orange gradient
      .partner-icon.dreami   — green gradient
      .partner-icon.khayfer  — coral-to-red gradient

  section#gleam-bonus  [aria-labelledby="gleam-heading"]
    Purpose: Primary giveaway entry section — Gleam.io widget embed.
    Contains: h2 (data-key="gleamTitle"), .gleam-card > p.gleam-desc
              (data-key="gleamDesc"), Gleam <a> embed, Gleam <script>.
    IMPORTANT: The Gleam <script src="https://widget.gleamjs.io/e.js"> tag
               appears EXACTLY ONCE on the page, here. Do not add it elsewhere.
    Gleam widget URL: https://gleam.io/TJ05k/poncakeaa-khayfer-summer-giveaway
    Sticky bar CTA ("Enter Now") scrolls to this section via scrollToForm().
    Sticky bar hides when this section is ≥15% visible (IntersectionObserver).

  section.legal-section
    Purpose: Official rules and Meta disclaimer (legally required).
    Contains: h2.legal-title (data-key="legalTitle") and #legal-text
              (data-key="legalText"). legalText uses innerHTML (not textContent)
              because it contains <br> tags.

  footer.site-footer
    Contains: Copyright line (data-key="footerText").

  div#sticky-bar  [class="sticky-bar"]
    Purpose: Fixed bottom CTA bar. Shows when Gleam section is NOT visible.
    Behavior: Hidden via .hidden class which applies translateY(110%).
              Auto-hides when #gleam-bonus scrolls into view (threshold 0.15).
    Contains: button.sticky-enter-btn (data-key="stickyBtn", onclick="scrollToForm()").

────────────────────────────────────────────────────────────────────────────────
  JAVASCRIPT ARCHITECTURE
────────────────────────────────────────────────────────────────────────────────

All JS is in a single <script> block before </body>. No modules, no imports.
Uses var throughout (ES5-compatible). Sections in order:

  1. TRANSLATIONS OBJECT  (const translations)
     Top-level keys: "en" and "es"
     Each language object contains all UI strings.
     See "TRANSLATION KEY INVENTORY" section below for full key list.

  2. APP STATE
     var currentLang = "en"   — tracks active language ("en" or "es")

  3. LANGUAGE TOGGLE
     toggleLanguage()          — flips currentLang, calls applyLanguage()
     applyLanguage(lang)       — walks all [data-key] elements and sets
                                 textContent (or innerHTML for "legalText").
                                 Also updates [data-placeholder-key] elements'
                                 placeholder attribute. Calls renderPrizeItems().

  4. PRIZE ITEMS LIST
     renderPrizeItems(lang)    — reads translations[lang].prizeItems array,
                                 builds <li> HTML string, sets #prize-list.innerHTML.
                                 Called on init and on every language toggle.

  5. STICKY BAR
     scrollToForm()            — scrollIntoView({behavior:"smooth"}) on #gleam-bonus.
                                 Called by sticky bar button onclick.
     initStickyBarObserver()   — IIFE. Creates IntersectionObserver watching
                                 #gleam-bonus (threshold: 0.15). Adds/removes
                                 .hidden class on #sticky-bar.

  6. INIT
     init()                    — IIFE. Calls renderPrizeItems("en") on first load.

────────────────────────────────────────────────────────────────────────────────
  KNOWN ISSUES & INTENTIONAL DECISIONS
────────────────────────────────────────────────────────────────────────────────

  1. meta[name=theme-color] Firefox warning
     VS Code (and linters) flag this as unsupported in Firefox/Opera. It is
     intentionally kept because the primary audience scans a QR code on mobile,
     where Chrome (Android) and Safari (iOS) both support it. The warning is
     cosmetic and does not affect functionality.

  2. No backend / no data collection
     The page collects no user data. Gleam.io handles all entry collection
     through their platform. There is no server, database, or API call.

  3. Single-file architecture
     All HTML, CSS, and JS are in index.html by design — simplicity,
     zero build step, zero dependencies, easy GitHub Pages deployment.

  4. Vendor prefix order in .sticky-bar
     -webkit-backdrop-filter appears BEFORE backdrop-filter. This is correct
     and intentional per CSS best practices (vendor prefix first).

  5. font-size: 16px on inputs
     There are no form inputs currently (the custom form was removed), but if
     inputs are ever re-added, use font-size: 16px to prevent iOS Safari from
     auto-zooming on focus.

  6. legalText uses innerHTML
     All other data-key values use textContent for XSS safety. legalText is
     the only exception because it intentionally contains <br> tags. The value
     is hardcoded in the translations object (not user input), so this is safe.

  7. Gleam.io widget: the hardcoded desc text in HTML
     The .gleam-desc paragraph inside .gleam-card still contains the old
     fallback text "Complete bonus actions below for extra chances to win the
     Summer Gift Basket!" in the raw HTML. This text is immediately overwritten
     by applyLanguage("en") on init (via data-key="gleamDesc"), so it is never
     visible to users. The live text shown is from the translations object.

────────────────────────────────────────────────────────────────────────────────
  HOW TO MAKE COMMON CHANGES
────────────────────────────────────────────────────────────────────────────────

  Change giveaway dates:
    → Update heroDates and heroAnnounce in BOTH en and es translation objects.
    → Update legalText in both en and es (contains hardcoded dates).
    → Update the hardcoded fallback text in the HTML hero section (data-key
      elements show their fallback text before JS runs).

  Change prize items:
    → Edit the prizeItems array in BOTH en and es translation objects.
    → Do NOT touch #prize-list in the HTML — it is populated by JS.

  Change a social media URL:
    → Find the <a href="..."> in the partners section HTML.
    → Replace the href value only. Button text is managed by data-key.

  Change partner descriptions:
    → Edit poncakeDesc / dreamiDesc / khayferDesc in BOTH en and es.

  Add a new section:
    → Add HTML inside div.page-wrapper before the sticky-bar div.
    → Add corresponding CSS block inside the <style> tag.
    → If bilingual, add translation keys to both en and es objects.
    → Add data-key="yourKey" attributes to elements that need translation.

  Change the Gleam widget:
    → Replace the href on the <a class="e-widget no-button"> with the new URL.
    → The script tag does not need to change.

  Re-add a custom form:
    → Previous form code existed before commit 21798f7. You can reference git
      history. The form collected name, email, and phone — but had no backend.
      If re-adding, wire it to Formspree, Netlify Forms, or similar service.
